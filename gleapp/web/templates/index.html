Import hash set

An MD5 / SHA-1 / SHA-256 list (one per line, or hash,category), a CSV/TSV, a Project VIC JSON, or a CAID export. Every file in the case whose hash is on the list is flagged; if the list asserts a category, an uncategorized match adopts it.

Add evidence to this case

Ingest another folder, extraction archive (.zip/.tar), E01 acquisition, or Project VIC/job .json into this case. New files are hashed, thumbnailed and checked for duplicates against everything already here; files already processed are left alone.

Reference data

Snapshots

Standalone copies of the whole case. Taken automatically every 10 min while you're editing and when the case closes, plus whenever you save one here. Restore saves the current state first, so it's undoable.

Processing history

Every run recorded against this case — ingest, processing, screening, hash-set matching, carving and examiner edits — newest first. A process run lists each stage and whether it succeeded or failed. This is the case audit log; it is also written into the LAVA export.

Maps

GLEAPP ships no map data and fetches none. Import a basemap file once and the gallery draws maps from it, offline, and the report names the file used. A .pmtiles region cut from the Protomaps build is the recommended form (see the README's Maps section for the one command that makes one); a raster .mbtiles made with QGIS or MapTiler Desktop also works.

Local hash stash

A private, on-this-machine list of the MD5 hashes of every file you categorize as 1 CAM, 2 Child Exploitative or 3 CGI/Animation. It is checked automatically in every case you process from now on — a matching file is flagged STASH and, if still uncategorized, adopts the category you stashed it under. You always confirm the final call.
